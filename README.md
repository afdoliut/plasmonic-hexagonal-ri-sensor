# Asymmetric Hexagonal Plasmonic Refractive Index Sensor Model

COMSOL FEM simulation model and MATLAB scripts accompanying our peer-reviewed publication:

>T. Afdol, M.O. Faruque, R. Al Mahmud, R.H. Sagor, A.K. Nahin, M.A.A. Aumi,
K.M.S. Hasan, S. Sazid and N.M.N. Nasser (2023). Numerical analysis of an asymmetric hexagonal plasmonic refractive index sensor model based on metal-insulator-metal and Si-insulator-Si waveguide. Sensing and Bio-Sensing Research, Netherlands, Elsevier: ScienceDirect.

>DOI: 10.1016/J.SBSR.2023.100563
